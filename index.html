Soccer Clip Compiler

React Vite Flask Python OpenCV Tesseract OCR FFmpeg StatsBomb API

Full-stack app that generates soccer highlight reels by syncing broadcast video with StatsBomb event data using OCR-extracted match timestamps. A broadcast clock detection pipeline built on OpenCV and Tesseract maps match time to video time for precise navigation despite replays and cuts, while a context-aware clip extractor identifies possession boundaries (Ball Receipt → Pass → next receipt) for semantically accurate segments. FFmpeg stream copy with input-side seeking cut compilation time from minutes to seconds on 1080p footage, and an interactive timeline lets users browse 3,500+ match events and export compiled clips.
